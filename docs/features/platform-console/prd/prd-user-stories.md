# User Stories: 平台控制台

## Story 1: 登录进入工作台并切换应用

**As a** 普通用户
**I want to** 用已有账号登录控制台、看到我的信息与应用入口、单点跳转到 e-cam-web
**So that** 我能从统一入口进入云管，而无需在多个应用重复登录

**Acceptance Criteria:**
- Given 浏览器同域访问控制台
- When 输入有效账号密码（或走 LDAP/passkey/MFA）提交登录
- Then 进入工作台，展示我的信息与应用快捷导航

- Given 已登录
- When 点击「云管」应用入口
- Then 单点跳转到 e-cam-web 且不提示重复登录

- Given 未登录且浏览器不支持 WebAuthn
- When 打开登录页
- Then passkey 入口不渲染，显示「改用密码/LDAP 登录」提示，无 JS 报错

- Given 账号已启用 MFA
- When MFA 连续失败 5 次
- Then 账号锁定 15 分钟，提示剩余解锁时间；锁定期间凭正确密码亦不可登录

- Given 登录提交失败（网络错误或 eiam 不可用）
- When 提交登录表单
- Then 已输入内容保留、显示明确错误与重试入口，不白屏；凭据错误文案不泄露用户名是否存在

## Story 2: 平台管理员治理平台身份

**As a** 平台管理员
**I want to** 对平台用户/组织/租户/身份源做增删改查
**So that** 我能维护平台整体身份目录与登录方式

**Acceptance Criteria:**
- Given 平台管理员已登录
- When 在用户管理页新增/编辑/删除一个平台用户
- Then eiam 侧数据同步变更，操作成功返回后列表 ≤ 2 秒内刷新并显示该变更

- Given 平台管理员已登录
- When 配置一个身份源（如 LDAP）
- Then 配置保存后，该身份源可用于登录

- Given 平台管理员已登录
- When 新增/编辑用户提交被拒（字段校验失败、用户名重复或 eiam 返回错误）
- Then 对应字段标红并回显错误原因、表单数据保留、列表数据不变；修正后可重新提交

## Story 3: 租户管理员在租户边界内治理

**As a** 租户管理员
**I want to** 管理本租户内的用户/角色/授权（可绑定已有策略，不可增删策略定义）
**So that** 我能维护本租户权限，而不影响其他租户

**Acceptance Criteria:**
- Given 租户管理员已登录且已选择租户
- When 查看用户列表
- Then 仅显示本租户用户，无法看到其他租户数据

- Given 租户管理员尝试操作超出租户边界
- When 发起越权请求（前端入口已被裁剪；直接调接口或经 URL 访问）
- Then eiam 返回 403，页面内提示无权限并保持当前页（不跳转登录页），数据不变

## Story 4: 管理员分配角色与授权

**As a** 平台管理员或租户管理员
**I want to** 创建角色、绑定授权/策略并分配给用户
**So that** 用户获得与职责匹配的最小权限

> 口径：策略定义（UF-10）仅平台管理员可增删改；租户管理员仅在本租户内创建角色、绑定已有策略并分配给用户。

**Acceptance Criteria:**
- Given 平台管理员已登录
- When 创建策略定义与角色、绑定策略、分配给用户
- Then 该用户下一次请求即具备对应权限（逐请求判定，无需重新登录）

- Given 租户管理员已登录
- When 在本租户创建角色、从可绑定策略列表中选择并分配给本租户用户
- Then 绑定成功；可绑定策略仅含 eiam 返回的列表，无新建/编辑/删除策略入口

- Given 管理员删除某授权且删除成功
- When 该授权生效对象下一次发起携带原权限的请求
- Then 请求被拒（403）；如 eiam 有授权缓存，生效延迟 ≤ 30 秒（Phase 0 核查）

## Story 5: 只读/审计角色查看治理现状

**As a** 只读/审计角色
**I want to** 查看身份与权限页面
**So that** 我能审计合规，但无法改动任何配置

**Acceptance Criteria:**
- Given 只读角色已登录
- When 打开用户/角色/授权页面
- Then 增删改入口不渲染（不可用）；直接调用写接口时 eiam 返回 403，前端提示无权限且数据不变

- Given 只读角色已登录
- When 访问租户管理或策略管理
- Then 菜单入口不渲染；直接经 URL 访问时 eiam 返回 403，页面提示无权限且数据不变

## Story 6: 任意一侧登出即双侧失效

**As a** 平台控制台或 e-cam-web 的登录用户
**I want to** 在任一应用登出后，另一应用会话同步失效
**So that** 退出登录不留残留会话

**Acceptance Criteria:**
- Given 用户在两个应用中均有有效会话
- When 在控制台登出
- Then 已打开的 e-cam-web 会话在下一次请求时 401 并跳回控制台登录页

- Given 用户在 e-cam-web 登出
- When 回到控制台发起请求
- Then 控制台会话失效并回到登录页
