# 4.3: 组织管理页（UF-5）：组织树 + 详情/成员 + 上限保护

## Description
落地 /organizations：`orgList` store + `organizations.ts` api（list/create/update/delete）。左树右详情（2:3，树最小 280px），树 ≤1000 节点/深度 ≤8，超限禁建；删除被拒弹窗（下属/关联用户计数 + 确认置灰 E11）；键盘树导航。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 组织管理 UF-5：Layout（2:3 双栏）/States/Interactions（超限禁建/删除被拒弹窗）/Data Binding、键盘树导航 (ref: 组织管理)
- docs/features/platform-console/design/tech-design.md — C 档组织端点（树形 Page<Organization>，≤1000/深≤8）、Organization 模型 (ref: Interfaces / Data Models)

## Acceptance Criteria
- [ ] orgList store（统一契约）+ organizations.ts api（组织树 list/create/update/delete）+ 写前守卫/回读接入
- [ ] 组织树：层级渲染 + 选中节点加载右侧详情（名称/下属组织数/关联用户数）+ 成员列表
- [ ] 新增子组织/编辑/删除；删除被拒（E11）弹窗列下属组织数/关联用户数、确认按钮置灰
- [ ] 上限保护：深度达 8 或节点达 1000 时「新增子组织」禁用 + tooltip 提示（PRD 上限）
- [ ] 组织名 1–64 字符前端拦截；树节点名超宽单行截断 + title 全文；键盘 ↑↓←→/Enter 导航

## User Stories
Story 2（组织增删改查、删除校验无下属/无关联用户）承接。

## Hard Rules
树上限（≤1000 节点/深度 ≤8）前端硬拦截，超限禁止再建子级；删除校验通过前不得放行提交。
