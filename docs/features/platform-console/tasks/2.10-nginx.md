# 2.10: nginx 同域反代 + CSP 基线 + 回切三件套 location

## Description
落地 nginx 配置：`/api/iam/* → eiam:9000`、`/console/*` 静态托管（gzip_static）、回切三件套 location（注释行切换/双池 + 旧登录入口 301）、CSP 基线注入 + XFO/HSTS。控制台与 e-cam-web 同登录域、禁止跨域直连 eiam。

## Reference Files
- docs/features/platform-console/design/tech-design.md — 多方会话拓扑（nginx 同域入口）、部署与回切开关三件套、CSP 指令基线表 (ref: Architecture / Integration Specs / Security)
- docs/features/platform-console/prd/prd-spec.md — 性能需求（CDN 但须同登录域）、Security Requirements（CSP/XFO/HSTS 由 nginx 注入） (ref: Other Notes)

## Acceptance Criteria
- [ ] 反代：/api/iam/* → eiam:9000 /api/*；/console/* 静态托管 + gzip_static（构建产 .gz）
- [ ] 回切三件套 location：① /console 注释行切换或 upstream 双池 + reload ② e-cam-web 401 目标新旧双产物软链 ③ 旧登录入口 301 → /console/login（都对 nginx 层实现）
- [ ] CSP 基线注入（default-src 'self'、script-src 'self'、style-src 'self' 'unsafe-inline'、connect-src 'self'、img-src 'self' data:、frame-ancestors/object-src/base-uri）+ X-Frame-Options + HSTS
- [ ] 禁止跨域直连 eiam（connect-src 'self'）；cookie 域/属性以 1.2 矩阵为准（SameSite 承载 CSRF 前提）

## User Stories
Story 1（同域访问 / SSO）、Story 6（双侧登出 401 收敛跳控制台）的部署承载。

## Hard Rules
验收宿主必为 nginx 同域形态，禁止以独立端口 dev server 判定通过；CSP 起草=平台管理员、复核=eiam owner，随认证链路矩阵双签。

## Implementation Notes
- 仅修改：`nginx/` 配置（反代/静态/CSP/回切 location 注释）。
- 沿用 `:8888` 同域前例；CSP 按真实构建产物实测收敛（style-src 'unsafe-inline' 可去除则收紧并记录，由 5.6 收敛）。
