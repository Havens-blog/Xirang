# 2.3: 数据模型类型（Data Models TS 接口）

## Description
落地纯前端 TypeScript 类型（无 DB）：Envelope / ListQuery / Page 归一类型 + User/Tenant/Organization/IdentitySource/Role/Authorization/Policy/PolicyStatement/PolicyCondition/ConnParams/PasskeyRegistrationSession/SessionClaims/Ref/RoleRef/LoginResult。Policy 为 Statement 数组形，附归一规则注释。

## Reference Files
- docs/features/platform-console/design/tech-design.md — Data Models 全类型定义、Policy Statement[] 归一规则、User.status 词表 (ref: Data Models)
- docs/features/platform-console/design/tech-design.md — Envelope/ListQuery/Page 统一归一类型 (ref: Interfaces)

## Acceptance Criteria
- [ ] 领域模型全量：User / Tenant / Organization / IdentitySource / Role / Authorization / Policy / PolicyStatement / PolicyCondition 字段带类型与约束（与设计逐字段一致）
- [ ] 共享引用：Ref / RoleRef（分配以 code 为准）/ ConnParams（password 仅写）/ PasskeyRegistrationSession / SessionClaims / LoginResult（含 mfaRequired/mfaTicket/token/lockUntil）
- [ ] 统一归一：Envelope{code,msg,data} / ListQuery{offset,limit,keyword} / Page{total,items}
- [ ] Policy 为 Statement[]（effect Allow|Deny、actions/resources 非空数组、condition 可选），归一规则注释（扁平单 effect ≡ 单 Statement 数组；多 Statement 无法表达时上报 validation）
- [ ] 不确定字段显式标注 Phase 0 核查：User.orgRef / User.status 锁定态 / Organization 域（eiam 可能为 department）/ PolicyCondition.operator 词表
