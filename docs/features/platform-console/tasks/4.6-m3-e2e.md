# 4.6: M3 E2E：身份治理 CRUD + 边界（E7/E10/E11）

## Description
真实浏览器验证身份治理四页 CRUD 正向/负向/边界：E7 分页边界、E10 用户名格式、E11 依赖删除被拒、提交被拒字段标红回显、≤2s 刷新。证据回填 acceptance.md。

## Reference Files
- docs/features/platform-console/prd/prd-spec.md — M3 出口判据（CRUD 场景与 E7/E10/E11 通过）、E6/E7/E10/E11 场景定义 (ref: Milestones / Edge & Negative Scenarios)
- docs/features/platform-console/design/tech-design.md — Testing：正向+负向+边界≥1/3、逐条附证据 (ref: Testing)

## Acceptance Criteria
- [ ] 四页 CRUD 正向：用户/组织/租户/身份源 增删改查 → eiam 同步 → 列表 ≤2s 刷新显示变更
- [ ] 负向：提交被拒（字段校验/名称冲突/eiam 错误）→ 对应字段标红 + 回显原因 + 表单保留 + 列表不变
- [ ] E7：分页超界回落最后页、空页空态、删除末页唯一记录回退上一页
- [ ] E10：用户名非法（长度/字符集）前端即时拦截，唯一性 eiam 反馈
- [ ] E11：删除被依赖对象（下属组织/关联用户/用户绑定）→ 弹窗列阻断计数、确认置灰
- [ ] 证据回填 acceptance.md 对应 M3 场景项（Playwright 用例链接）

## User Stories
Story 2（身份治理 CRUD + 提交被拒回显）、Story 4（角分配/绑定）的身份治理闭环承接。

## Hard Rules
验收宿主必为 nginx 同域形态；≤2s 刷新以真实运行时序断言，不得以缩短等待绕过。
