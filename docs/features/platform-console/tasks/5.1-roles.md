# 5.1: 角色管理页（UF-8）：角色详情/绑定子页

## Description
落地 /roles + 角色详情/绑定子页（/roles/:id）：`roleList` store + `roles.ts` api（list/create/update/delete、role/policy batch_assign 绑定）。角色列表（名/所属租户/绑定策略数/绑定用户数）、新增/编辑、删除被拒（E11）、子页策略绑定多选 + 用户绑定多选。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 角色管理 UF-8：Layout/States/Interactions/Data Binding、角色详情子页（双多选整页承载） (ref: 角色管理)
- docs/features/platform-console/design/tech-design.md — A 档 role 端点（desc 非 description、batch_assign code 为准）、C 档 role/policy 绑定与 attached/users、Role 模型 (ref: Interfaces / Data Models)

## Acceptance Criteria
- [ ] roleList store（统一契约）+ roles.ts api（list/create/update/delete + policy/users batch_assign/unassign）+ 写前守卫/回读接入
- [ ] 角色列表：角色名/所属租户/绑定策略数/绑定用户数/操作；新增 Dialog（角色名 1–64 租户内唯一）
- [ ] 角色详情子页：策略绑定多选（租户管理员仅列 eiam 返回的可绑定策略，无新建/编辑策略入口）+ 用户绑定多选（支持搜索），整页承载双多选
- [ ] 删除被拒（E11）：校验无用户绑定，被拒提示绑定用户数并阻止
- [ ] 单条角色按 id 查询填充子页；保存返回列表 ≤2s 刷新

## User Stories
Story 3（租户管理员租户内角色）、Story 4（创建角色绑定策略分配用户、可绑定策略仅 eiam 列表无策略定义入口）承接。

## Hard Rules
租户管理员策略绑定下拉仅列 eiam 可绑定策略、无新建/编辑/删除策略入口；角色名租户内唯一（eiam 校验）。

## Implementation Notes
- 仅新增：`src/views/roles/`（列表 + 详情子页）、`src/stores/roleList.ts`、`src/api/roles.ts`。
- 角色 attatched/users 与 attached/policies 的端点方向（C 档推定、与 A 档 role/list/attached/user 相反）Phase 0（1.1）核验后固化；Role.desc 字段名（非 description）对齐 A 档实盘。
