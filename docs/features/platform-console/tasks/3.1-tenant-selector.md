# 3.1: TenantSelector 共享组件 + 租户切换闭环（写前守卫/跨标签一致性）

## Description
落地 TenantSelector 共享组件（主布局 header + 租户选择页复用）+ 应用切换器 + 租户切换闭环：切租户 → `POST /api/iam/tenant/switch`（X-Active-Tenant-ID）→ 整页 `location.replace()`。论证并落地写前守卫 + 响应回读比对的跨标签一致性。

## Reference Files
- docs/features/platform-console/design/tech-design.md — Integration Specs 6 跨标签租户一致性（真相源/强制刷新/响应回读/写前守卫/显式接受边界） (ref: Integration Specs)
- docs/features/platform-console/design/tech-design.md — tenant/switch 语义（销毁旧 session 重签 JWT、调用方 reload）、应用切换器 (ref: Interfaces / Architecture)

## Acceptance Criteria
- [ ] TenantSelector 组件：读取 user store 所属租户列表，勾选目标 → 调 tenant/switch（X-Active-Tenant-ID 头）→ 整页 location.replace()，挂载主布局 header（替换 2.8 占位）与租户选择页共用
- [ ] 应用切换器：新标签打开 e-cam-web（v1 仅「云管」一项，穷举本地枚举）
- [ ] 写前守卫：create/update/remove 提交前比对页面进入快照与 currentTenantId，不一致先刷新再提交（模块级单值快照，非持久化）
- [ ] 响应回读比对：list store fetch 成功后回读响应租户标识与 currentTenantId 比对（响应无标识则跳过），不一致丢弃渲染 + location.replace 自愈
- [ ] 显式接受边界登记：写守卫仅覆盖控制台 7 个 list store；e-cam-web/ecmdb-web 写路径无守卫（服务端强制授权，登记）

## User Stories
Story 3（租户边界）、Story 1（应用切换单点跳转）的租户上下文承载。

## Hard Rules
切租户必走 tenant/switch + 整页 reload，禁止仅换 store 不刷页的 SPA 路径；写前守卫为控制台写错误的硬门，不得绕过。

## Implementation Notes
- 仅修改：`src/components/TenantSelector.vue`（共享组件）、`src/components/AppSwitcher.vue`、`src/utils/`（写前守卫 + 回读比对工具）、`src/layouts/MainLayout.vue`（挂载）。
- 写前守卫/回读比对是 4.x/5.x 各 list store 的公共依赖，本任务产出工具后由各页 create/update/remove 接入。
