# 2.5: 文案契约 map + 契约渲染组件

## Description
落地文案契约 keys→逐字文案 map（ui-design 文案契约全表）+ 契约渲染组件（纯文本渲染，禁用 v-html）。ApiError.message 即契约文案，视图零二次映射；字段级错误经 aria-describedby 就近输出。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 文案契约全表（auth.*/session/forbidden/tenant.*/eiam.unavailable/grant.duplicate/delete.*/validation.name_exists/save.conflict）与「实现不得改写措辞」约束 (ref: 文案契约)
- docs/features/platform-console/design/tech-design.md — 文案契约 code→逐字文案映射表、ApiError.message=契约文案、视图零二次映射 (ref: Error Handling)

## Acceptance Criteria
- [ ] 全 key map 落地：auth.invalid_credentials/auth.mfa_invalid/auth.account_locked/auth.empty_credentials/auth.passkey_unsupported/auth.first_login_change_password/session.expired/forbidden/tenant.none/tenant.disable_blocked/eiam.unavailable/grant.duplicate/delete.blocked_org/delete.blocked_role/delete.blocked_policy/validation.name_exists/save.conflict，逐字一致
- [ ] 契约渲染组件：纯文本渲染 eiam 返回内容，禁用 v-html；字段错误经 aria-describedby 就近输出
- [ ] auth.account_locked / tenant.disable_blocked 等带占位符（{X} / {n} / {m}）文案的参数插值正确

## User Stories
No direct user story mapping.（横向基础设施）

## Hard Rules
实现不得改写任何契约文案措辞；eiam 返回内容一律纯文本/组件化渲染，禁用 v-html。

## Implementation Notes
- 仅新增：`src/utils/` 文案契约 keys 常量 + `src/components/` 契约渲染组件（3 共享组件之一）。
- v1 仅中文，按 key 维护以备 i18n；字段级校验文案（非本契约）由各表单 aria-describedby 就近维护。
