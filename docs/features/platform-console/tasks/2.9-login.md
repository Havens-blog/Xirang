# 2.9: 登录页（UF-1）：密码/LDAP/passkey + MFA + 锁定/强制改密

## Description
落地登录页 + `api/auth.ts`：登录方式 Tab（密码/LDAP/passkey，WebAuthn 不可用隐藏 passkey）、表单校验、MFA challenge、强制改密（E1）、账号/方式级锁定倒计时、中性错误条（不泄账号）。成功 → 租户选择分流（0/1/≥2）。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 登录页 UF-1：Layout/States（Default/MFA/强制改密/Loading/Error/Locked）/Interactions/Data Binding (ref: 登录页)
- docs/features/platform-console/design/tech-design.md — B 档登录端点（system/ldap/passkey login + mfa verify）与 LoginResult（lockUntil 倒计时） (ref: Interfaces)

## Acceptance Criteria
- [ ] 登录方式 Tab：密码/LDAP/passkey 三 Tab；浏览器不支持 WebAuthn → 隐藏 passkey 入口 + 提示改用密码/LDAP（无 JS 报错，E8）
- [ ] 表单校验：空凭据前端拦截（auth.empty_credentials）；错误凭据统一文案「用户名或密码错误」不泄账号（E2 中性文案）
- [ ] MFA challenge：6 位码输入，连续 5 次失败锁定 15 分钟（auth.account_locked，剩余倒计时，E9）
- [ ] 强制改密态：初始密码首次登录触发（auth.first_login_change_password，E1 骨架，改密端点形状 Phase 0 核实）
- [ ] auth.ts api：system/ldap/passkey 登录 + mfa verify + logout，经 unwrapEnvelope 解包
- [ ] 成功 → 按 must_select_tenant/所属租户数分流（0 受限工作台 / 1 自动选定 / ≥2 租户选择页）

## User Stories
Story 1（登录→工作台）全部 AC 承接（含 E8/E9/E2、eiam 不可用不白屏、凭据错误不泄账号）。

## Hard Rules
锁定/错误文案走文案契约，禁止回显账号信息或泄露用户名是否存在；凭据错误与用户不存在返回同一文案。

## Implementation Notes
- 仅修改：`src/views/login/`（或 views/Login.vue）+ `src/api/auth.ts`。
- LoginResult.lockUntil 是剩余解锁倒计时唯一数据源；eiam 不携带时降级为中性固定文案（不前算）。
- 分流依赖 2.7 user store（must_select_tenant / tenants）；租户选择页（3.2）/受限工作台（3.3）在后续里程碑。
