# 5.2: 授权管理页（UF-9）：三元组词表 + 撤销 pending 态

## Description
落地 /authorizations：`authorizationList` store + `authorizations.ts` api（list/create/revoke、三元组词表枚举）。表格（主体/资源/动作/操作）、新增（三下拉枚举 + 唯一性预检）、撤销（确认 → pending 态 ≤30s aria-live 播报后移除）。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 授权管理 UF-9：Layout/States（撤销 pending 态）/Interactions/Data Binding（三元组词表下拉） (ref: 授权管理)
- docs/features/platform-console/design/tech-design.md — C 档授权词表枚举端点、Authorization 三元组模型、grant.duplicate 唯一性 (ref: Interfaces / Data Models)

## Acceptance Criteria
- [ ] authorizationList store（统一契约）+ authorizations.ts api（list/create/revoke + 词表枚举 {subjects,resources,actions}）
- [ ] 新增授权：主体/资源/动作三下拉枚举（非自由文本），三元组唯一性前端预检（grant.duplicate）+ eiam 服务端兜底拒绝
- [ ] 撤销：确认弹窗 → 行进 pending 态（行内徽标「生效中」+ 操作禁用）→ 生效（≤30s）后刷新移除该行
- [ ] pending 态经 aria-live="polite" 播报（时变信息不以纯视觉传达）
- [ ] 词表来源 = eiam 枚举端点；Phase 0 未确认现成提供则临时降级为 parity-checklist 登记的静态词表并标注来源版本

## User Stories
Story 4（管理员分配授权、删除授权后请求被拒 403/生效延迟 ≤30s 核查）承接。

## Hard Rules
主体/资源/动作只能从 eiam 返回词表选取，不支持自由文本；同一（主体,资源,动作）组合唯一（前端预检 + eiam 兜底）。

## Implementation Notes
- 仅新增：`src/views/authorizations/`、`src/stores/authorizationList.ts`、`src/api/authorizations.ts`。
- 词表端点形状（C 档推定 σ{subjects,resources,actions}）Phase 0（1.1）核验；撤销生效延迟 ≤30s 若 eiam 无授权缓存则即时生效（Phase 0 核查）。
