### 4. Conventions Established
- **切租户闭环强制刷新约定**：所有切租户路径（UF-11 首选、UF-2 切换器）成功后必走 POST /api/iam/tenant/switch → 整页 location.replace()，杜绝 SPA 内只换 store 不刷页（Hard Rule，tech-design §Integration 6）。
- **写前守卫硬门**：create/update/remove 提交前调 enforceWriteGuard 比对页面进入快照与 currentTenantId，不一致先 location.replace 自愈再 return false 阻断写；快照取 router 2.6 getPageEnterTenantSnapshot 模块级单值（非持久化、非第二份真相）。4.x/5.x 各 list store 写路径必须接入。
- **响应回读比对**：list store fetch 成功后调 assertResponseTenantMatch 回读响应租户标识，无标识跳过、不一致丢弃渲染 + 自愈 reload。4.x/5.x 各 list store fetch 必须接入。
- **显式接受边界登记**：写守卫仅覆盖控制台 7 个 list store；e-cam-web/ecmdb-web 写路径无守卫（服务端强制授权），登记为显式接受，UI 表现继续呈现旧租户快照至下一次请求。
- **角色字段派生口径（provisional）**：eiam profile 无 roles 字段，角色标签由 isAdmin+tenants 经 menuConfig.inferRole 派生（与菜单裁剪同信号源）；未来若 eiam 补 roles 字段需同步收敛。
- **零租户受限态门控下沉组件**：tenant.none 契约文案统一由组件承载，平台管理员豁免；管理页（4.x/5.x）URL 直入的 tenant.none 提示承接属后续任务范围。
- **E2E 验收宿主**：必为 nginx 同域形态 :8888/console（baseURL=localhost）；E3/E4 在 dev eiam 无法 provision 账号时允许 CONTRACT 履约，与 M1 同口径透明标注。
- **调试钩子安全约束**：window.__hcDebug 仅 localhost 暴露既有函数、不绕过鉴权、hostname 非 localhost 零暴露。

### 5. Deviations from Design
- **[3.1] AppHeader 同步修改**：tech-design 视图映射将 TenantSelector 挂载归于 MainLayout；实现为满足 AC-1「替换 2.8 占位」（占位物理位于 AppHeader）同步修改 AppHeader.vue 占位 div → slot。MainLayout 仍为挂载点，符合设计意图，属实现细节补充。
- **[3.2] ≥2 用 el-select 单选而非 radio**：ui-design §概念为「单选 radio」；实现优先任务指令「Reuse the 3.1 TenantSelector component」+ DRY，以 el-select 承载单选语义。单选语义一致，视觉控件形态不同，属受任务指令授权的取舍。
- **[3.3] 角色字段派生而非读 profile.roles**：parity §6.1.4 实核 eiam profile.user 无 roles 字段，Hard Rule 禁止加端点 → 由 isAdmin+tenants 经 menuConfig.inferRole 派生档位标签。与设计「profile 只读四字段」的字段集一致（角色字段来源改为派生），属 parity 核查驱动的实现修正，provisional 口径已登记。
