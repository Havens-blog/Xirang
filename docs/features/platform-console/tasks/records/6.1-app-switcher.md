## Summary
将 AppSwitcher 从「el-dropdown 单应用（云管）」升级为平台导航面板（参照 e-cam-web
PlatformNav，e-cam-web/src/components/PlatformNav/index.vue）：Teleport 居中面板 +
遮罩、左侧「我的收藏」列 + 分组入口列（控制台 8 模块 + 云管 5 分区块 3-3-2-2-3 深链）、
每入口 ☆/★ 收藏切换、收藏列悬停 ✕ 移除、localStorage 持久化（key
`haven-platform-nav-favorites`，shape {key,title,desc,path,external} 与 e-cam-web 同构、

/cam，深链形与 PlatformNav 同源）。零租户受限态（!isAdmin && tenants.length===0）与 v1
同口径隐藏；控制台列入口按 P0 权限码过滤（策略/租户叠加 requiresAdmin 双闸，与菜单/路由
守卫同口径），云管列跨应用不裁剪（服务端校验兜底）。
