## 4. Conventions Established
- 权限三页统一采用「store（统一契约 + 写前守卫 + 响应回读 + 401 收敛）+ api 客户端（D-x parity 归一）+ Vue 页面」三层结构，与 M2/M3 三页一致
- eiam 单数/复数分歧统一在 api 层归一（D-5：statement→statements / action→actions / resource→resources），规范类型保持最小不动，api 层定义 *WithMeta 承载操作键与计数
- 计数策略：响应直出优先（policy assignment_count），无直出则 store enrichCounts 并行 Promise.allSettled 降级 0（role policy_count/user_count），上限 100 显示 '100+'
- 校验双轨：前端纯函数 JSON/结构校验（标红字段 + 阻止保存）→ eiam 服务端 schema 校验失败（validation kind 标红映射）；契约文案统一经 contractText 渲染
- 越权处理双形态：守卫级（route meta.requiresAdmin）非 admin → /forbidden；请求层跨租户写 HTTP 403 → 原地 inline 提示不跳转
- 撤销/异步生效态：pending 入 store（行内徽标 + 操作禁用 + aria-live='polite'），≤30s Promise.race 超时强制 fetch 对账
- E2E 验收宿主硬规则：nginx 同域 :8888/console 生产构建产物 + chromium 真实浏览器 + 零 mock 会话；REAL/CONTRACT 双档（REAL 真 eiam e2e_ 前缀自清理，CONTRACT 承载可控信封）
- RC 迁移两提交拆分：A=页面/API/类型删除，B=路由/菜单/导航删除；死代码 grep 复核 + 并发脏文件显式 pathspec；授权状态诚实记录（已签/待签不伪造）
- doc 交付工件（teardown-checklist / deploy-hardening）登记判据与会签位，不在提案内执行下线/上线本身；未处置项保持未就绪
- 部署加固同运维面原则：探活/告警复用 e-cam-web + WatchAlert 同探测器同渠道，不新增独立 SLA；CSP 收敛按真实构建产物逐指令测量 + staging DevTools 零违规为最终放行门
