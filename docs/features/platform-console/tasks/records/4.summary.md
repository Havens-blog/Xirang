## 4. Conventions Established
- **list store 统一契约**：{items,total,page,pageSize(default 20, cap 100),loading,error} + fetch/create/update/remove + 每端点 AbortController（fetch 前中断在途）。userList 为首份范本，orgList/tenantList/idpList 复用。E7 分页边界（page 超界回落末页重查/末页空回退/切过滤重置 page=1）由 store 承载。
- **401 复位**：store 经 registerUnauthorizedReset 自助注册回调，避免守卫反向依赖 list store。
- **写前守卫（硬门）**：create/update/remove 提交前 enforceWriteGuard 前置比对租户快照，测试验证阻断；4.2/4.3/4.4/4.5 全接入。
- **状态展示三态词表**：eiam 原值经 normalizeStatus 归一为 启用/禁用/锁定(占位)，未知串不崩；StatusBadge 软着色用 CSS 变量（语义色 16% 透明底+语义文字），浅色主题 color-mix 加深保 AA，禁用走 neutral（非 danger）。
- **eiam 响应归一**：status int→string 在 api 层归一（与 User.status normalizeStatus 同口径，G-9 无 locked）。
- **删除前置预检客户端化**：客户端算阻断计数（树 child_count + members user_count），二者均 0 方可提交；eiam 拒绝作后置兜底，前端不依赖拒绝消息结构。
- **Bind 密码 write-only**：永不回显/永不预填/blank=unchanged，服务端+客户端双守。
- **页面交互不写组件测试**（TECH-testing-002）：页面级交互由 E2E 承接，单测聚焦 store 契约 + api 映射归一。
- **E2E REAL/CONTRACT 双档**：正向 CRUD + 列表读 + 前端即时拦截走 REAL admin 真链路（零 page.route，e2e_ 前缀 try/finally 自清理）；边界/唯一性/依赖删除/写操作避污染走 CONTRACT；≤2s 刷新双重断言不缩短等待。
- **文案出口**：阻断/错误文案走 copyContract（如 tenant.disable_blocked {n}=count）。
