## Key Decisions
- **生产代码不动**：本轮全部竞态源于测试夹具与并发语义的观测方式，生产路径
  （channel 收敛、意图性 fire-and-forget 审计）保持原设计
- **异步语义以「锁化观测 + 轮询」承载**：不与产品的异步行为对抗，只让测试侧
  建立 happens-before
- **secrets 预检而非 YAML `if` 直接引用**（GitHub 禁止在 job 级 `if` 用 secrets
  上下文）：步骤级 `id + outputs + if` 门控，缺配置绿、配齐即满血
- **惰性嵌套工作流删除**：GitHub 只执行根级，嵌套只迷惑人；删除不丢历史
