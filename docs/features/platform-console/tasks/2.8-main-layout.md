# 2.8: 主布局 MainLayout（侧边栏分组菜单 + header）

## Description
落地主布局壳：左侧边栏（220px↔64px 折叠、分组菜单 8 项按角色裁剪、active/hover 态、logo 区）+ 顶部 header 56px（折叠按钮、面包屑、主题切换、用户头像下拉（登出）、用户名）。router-view outlet + 内容区。应用切换器与租户选择器位置预留。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 主布局 UF-2：布局骨架、侧边栏分组菜单按角色裁剪、header 元素、401/403/受限态 (ref: 主布局)
- docs/features/platform-console/design/tech-design.md — 布局骨架（侧边栏 + header）、401 收敛、租户选择器/应用切换器数据源 (ref: Architecture)

## Acceptance Criteria
- [ ] 侧边栏：220px↔64px 折叠（300ms 过渡，<1024px 转抽屉）、分组菜单 3 组 8 项、active=accent-primary 15% 底+accent-blue 文字、hover=bg-hover、logo 区点击回工作台
- [ ] 菜单按角色裁剪：普通用户仅工作台；只读/审计见 工作台/用户/组织/身份源/角色/授权 只读；租户管理员见 工作台/用户/角色/授权；租户管理/策略管理仅平台管理员
- [ ] header：折叠按钮 + 面包屑（首页/当前页）+ 主题切换（月/日）+ 用户头像（渐变）+ 用户名 + 头像下拉（登出）
- [ ] 折叠态图标带 tooltip + aria-label；登出调 logout 销毁会话
- [ ] 403 原地 toast、401 跳登录、零租户受限态（租户选择器禁用占位 + 应用切换器隐藏）三态

## User Stories
Story 1（统一导航）、Story 5（菜单裁剪 + 只读不渲染增删改入口）、Story 6（登出）的壳层承接。

## Hard Rules
菜单裁剪与各 UF Validation Rules 的可见口径逐项一致（租户管理/策略管理仅平台管理员渲染）；租户选择器/应用切换器在 3.1 挂载前占位。

## Implementation Notes
- 仅修改：`src/layouts/MainLayout.vue` + 依赖的侧边栏/header 子组件（components/ 下）。
- 应用切换器（新标签开 e-cam-web）与租户选择器为 3.1 TenantSelector 共享组件，本任务只留挂载点与 header 结构。
