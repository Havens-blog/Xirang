# 4.1: StatusBadge 共享组件（状态归一词表徽章）

## Description
落地 StatusBadge 共享组件（7 个列表页共用的状态徽章）：启用/禁用/锁定三态，success/warning 语义色仅用于状态与结果反馈，不硬编码色值。状态归一词表（eiam 原值 → 展示态）。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 状态徽章映射（启用=accent-green/禁用=tag-bg/锁定=color-warning，16% 透明底 + 语义色文字，AA 对比度） (ref: Design System)
- docs/features/platform-console/design/tech-design.md — Data Models User.status 归一（'active'|'disable'|'unknown'）与共享组件清单 (ref: Data Models / Architecture)

## Acceptance Criteria
- [ ] 三态徽章：启用（accent-green 底）、禁用（tag-bg + text-regular）、锁定（color-warning 底）；浅色主题经 color-mix 加深保 AA
- [ ] 状态归一词表：eiam 原值（'active'/'disable'/未知串）→ 展示态（启用/禁用/锁定），未知串归一处理不崩
- [ ] 徽章软着色实现为语义色 16% 透明底 + 语义色文字，不硬编码色值；icon-only 场景带 aria-label
- [ ] 供 7 个列表页复用；脱离具体页面的纯展示组件，单测覆盖词表归一

## User Stories
No direct user story mapping.（共享组件）

## Hard Rules
success/warning 语义色仅用于状态与结果反馈，不作装饰；danger 保留给删除/危险操作，状态列不得硬编码色值。

## Implementation Notes
- 仅新增：`src/components/StatusBadge.vue` + 状态词表映射模块 + 单测。
- eiam 锁定态的暴露方式以 Phase 0（1.1/1.3）结论回填；未核验前「锁定」态按词表占位、缺数据则降级为禁用态展示。
