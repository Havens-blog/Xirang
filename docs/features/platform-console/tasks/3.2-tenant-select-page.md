# 3.2: 租户选择页（UF-11）：0/1/≥2 分流

## Description
落地 /tenant-select：认证通过后按所属租户数分流 —— 0 个直达受限工作台（平台管理员豁免）、1 个自动选定直达工作台、≥2 个渲染租户单选列表。tenant_id 写入共享 session。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 租户选择 UF-11：Layout/States（Loading/多租户/单租户/零租户/Error）/Interactions/Data Binding (ref: 租户选择)
- docs/features/platform-console/design/tech-design.md — 租户分流语义与 tenant_id 写入共享 session（口径 Phase 0 核查） (ref: Integration Specs)

## Acceptance Criteria
- [ ] 分流：所属租户 0 → 归档至受限工作台（仅欢迎+我的信息）；1 → 自动选定唯一租户直达工作台（toast 短暂提示）；≥2 → 渲染单选列表
- [ ] 平台管理员豁免零租户：零所属租户仍可进入管理页（不落地受限处置）
- [ ] 选租户 → 写 session tenant_id → 走 tenant/switch（3.1 组件）→ 工作台
- [ ] 查询失败 → 错误提示 + 重试（返回 Loading 态）；列表仅含 eiam 返回的所属租户，不可自由输入 tenant_id

## User Stories
Story 1（登录后进租户选择）、Story 3（租户边界，含平台管理员豁免）的租户分流承接。

## Hard Rules
租户列表仅来自 eiam 返回的所属租户，禁止自由输入任意 tenant_id；未选定前不进入管理页。

## Implementation Notes
- 仅修改：`src/views/tenant-select/`（或 views/TenantSelect.vue）+ 路由（2.6 已注册 /tenant-select）。
- 分流判定源 = user store（must_select_tenant / tenants）；受限工作台复用 3.3 工作台的受限视图组件。
