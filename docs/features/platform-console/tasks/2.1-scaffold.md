# 2.1: 项目脚手架与依赖锁定（haven-console 新仓）

## Description
新建 `haven-console` 独立仓：package.json / vite.config.ts / tsconfig.json / 目录骨架，pnpm ≥9 且 package.json `packageManager` 锚定（lockfile 锁死），依赖与 e-cam-web 锁同版本。vue-tsc typecheck + vite build 可跑通。

## Reference Files
- docs/features/platform-console/design/tech-design.md — 技术栈与版本、目录树（src/api·stores·router·layouts·components·views·utils + e2e + nginx）、pnpm packageManager 锚定 (ref: Overview / Architecture)
- docs/features/platform-console/ui/ui-design.md — 设计系统依赖 Sass + theme 令牌（脚手架需声明 sass 依赖） (ref: Design System)

## Acceptance Criteria
- [ ] 仓初始化：package.json / vite.config.ts / tsconfig.json / pnpm lockfile；packageManager 字段锚定 pnpm ≥9 精确版本
- [ ] 依赖锁同版本：vue 3.5 / vite 7 / typescript 5.9 / vue-router 4.5 / pinia 3(+persistedstate) / element-plus 2.10(+@element-plus/icons-vue) / axios / sass / vitest 4 / happy-dom / playwright 1.55 / @vue/test-utils / unplugin-vue-components / unplugin-auto-import，版本以 e-cam-web package.json 为准逐项对齐
- [ ] 目录骨架：src/{assets/styles, api/{request + 模块}, stores, router, layouts, components, views, utils} + e2e/ + nginx/
- [ ] unplugin 按需 + manualChunks 三分包 + 路由懒加载基建（配置项已就绪，不含业务实现）
- [ ] `pnpm typecheck`（vue-tsc）+ `pnpm build` 在空骨架下通过；`pnpm test` 空跑可执行

## User Stories
No direct user story mapping.（基础设施）

## Hard Rules
版本以 e-cam-web 现有 manifest 为唯一基准逐项对齐，不得擅自升级/降级；packageManager 须显式锚定。

## Implementation Notes
- 仅创建以下文件/目录：`package.json`、`pnpm-lock.yaml`、`vite.config.ts`、`tsconfig.json`、`src/**` 骨架目录占位、`e2e/`、`nginx/`；不含任何业务逻辑。
- 3 分 vendor 包（element-plus / vue 生态 / 其余）与 `import()` 懒加载配置属本任务产出，供 2.6/性能预算使用。
