# 2.13: RC#2：e-cam-web 会话过期/401 跳转目标切换

## Description
把 e-cam-web 登录目标切到控制台 `/console/login`（原 ecmdb-web `/login`）。拆分互斥语义的 `VITE_ECMDB_LOGIN_URL` 为 `VITE_LOGIN_TARGET`（登录目标）与 `VITE_ECMDB_WEB_BASE`（个人中心基址，值不变），三处改读。

## Reference Files
- docs/features/platform-console/design/tech-design.md — RC#2 改动文件（index.ts:24 + user.ts:91 + MainLayout.vue:58）、变量用途拆分、验证与回退 (ref: 跨仓改动设计)

## Acceptance Criteria
- [ ] 拆分变量：`VITE_LOGIN_TARGET`（默认 `/console/login`，index.ts:24 与 user.ts:91 改读）+ `VITE_ECMDB_WEB_BASE`（值维持现 env，MainLayout.vue:58 改读，语义正名零行为变化）
- [ ] 401/登出跳转目标 → `/console/login`（不清共享 cookie）
- [ ] 修复隐式耦合：个人设置跳转基址不落死链（`/console/login/profile/index` 不出现）
- [ ] 验证：Playwright 断言会话过期后下一请求落 `/console/login` 且 cookie 未清（对齐 Story 6 AC）

## User Stories
Story 6（任一侧登出/过期后回到控制台登录页）的 e-cam-web 侧落实。

## Hard Rules
机制 = build 期 env 注入，不得散落硬编码；个人设置基址（过渡期）必须继续指向 ecmdb-web 根，不受 301 波及。

## Implementation Notes
- 仅修改（e-cam-web 仓）：`src/api/request/index.ts:24`、`src/stores/user.ts:91`、`src/layouts/MainLayout.vue:58` + env 变量定义；`src/api/request/eiam.ts` 仅调用不列改动。
- 回退：新旧目标双产物并存（各一份 dist），切换 = 静态目录软链。
### Test Impact
- Affected test suite(s): e-cam-web e2e/ 登录与会话过期用例；若有 platform 导航 smoke
- Expected fixture changes: 401 跳转断言的目标 URL 由 ecmdb-web /login 改为 /console/login
- Risk level: medium（跨仓契约变更，须与 e-cam-web 前端 owner 会签）
