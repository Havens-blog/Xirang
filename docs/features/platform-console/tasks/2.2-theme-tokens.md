# 2.2: 设计系统令牌拷贝 + 主题 store + 漂移登记

## Description
从 e-cam-web 拷贝 `theme-variables.scss` + `element-theme.scss`（Linear 靛紫令牌，深色默认 + 浅色双主题），落地 `theme.ts` store（persist key `hc_theme`），html 根节点切 `light` class。建 `shared-hashes.json` 登记拷贝面 sha256 × 源 commit，作为漂移防线数据源。

## Reference Files
- docs/features/platform-console/design/tech-design.md — 拷贝 + 锁同版本、Store 清单（theme 唯一 persist）、拷贝面漂移防线（shared-hashes.json + CI 对比） (ref: Overview / Architecture)
- docs/features/platform-console/ui/ui-design.md — 色彩令牌表、主题策略（深色默认、月/日切换、localStorage 持久化、不跟随系统） (ref: Design System)

## Acceptance Criteria
- [ ] 拷贝 theme-variables.scss + element-theme.scss，令牌与 e-cam-web 逐项一致（--accent-primary #5e6ad2 / --accent-blue #7170ff / --bg-* / --text-* / 语义色）
- [ ] theme.ts store：dark 默认，html root 切 `light` class，持久化 key `hc_theme`（persistedstate 仅挂本 store）
- [ ] 主题切换：`hc_theme` localStorage 读写；不跟随 prefers-color-scheme
- [ ] shared-hashes.json 登记 3 个拷贝面文件（theme-variables.scss / element-theme.scss / api/request/eiam.ts 若有）的 sha256 + 源仓 commit

## User Stories
No direct user story mapping.（视觉基础设施）

## Hard Rules
令牌/组件圆角/间距照抄 e-cam-web，不得自创品牌色或布局；除 theme 外任何 store 不得声明 persist。

## Implementation Notes
- 仅修改：`src/assets/styles/theme-variables.scss`、`src/assets/styles/element-theme.scss`、`src/stores/theme.ts`、`shared-hashes.json`、`src/main.ts`（挂 persistedstate 仅 theme）。
- 漂移防线完整链路（CI sha 对比）由 2.11 承接；本任务只负责登记数据源。
