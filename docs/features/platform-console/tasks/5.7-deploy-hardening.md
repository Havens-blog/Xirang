# 5.7: 部署与运维加固（探活监控 + 回切演练 + CSP 收敛）

## Description
落地运维加固：控制台探活健康检查接入告警（与 e-cam-web 同运维面）、回切开关演练 runbook（10 分钟内、含步骤/耗时/回退验证）、CSP 按真实构建产物实测收敛（style-src 'unsafe-inline' 可去除则收紧）。产出均落 nginx 配置 + runbook/记录。

## Reference Files
- docs/features/platform-console/prd/prd-spec.md — Monitoring Requirements（探活接入告警、回切演练 10 分钟内）、Security Requirements（CSP 注入） (ref: Other Notes)
- docs/features/platform-console/design/tech-design.md — 部署与回切开关三件套、CSP 指令基线（实测收敛）、回切演练计时 (ref: Integration Specs / Security)

## Acceptance Criteria
- [ ] 探活：nginx /console/health 探活接入告警，与 e-cam-web 同运维面
- [ ] 回切演练 runbook：三件套逐个演练（注释行切换/双池 + 静态软链 + 301），记录步骤/耗时/回退验证，≥10 分钟内可回切（PRD 承诺）
- [ ] CSP 收敛实测：按真实构建产物逐指令收敛，style-src 'unsafe-inline' 可去除则收紧并记录（不可去除则记原因）
- [ ] 双人复核登记：回切演练记录 + CSP 收敛结论入部署清单，平台管理员 + eiam owner 双签

## User Stories
No direct user story mapping.（运维加固承 PRD Monitoring/Security Requirements）

## Hard Rules
回切必须在 staging 完整演练一次并计时（未演练不得上线）；探活/CSP 改动不得绕过「同运维面 + 双签」约束。

## Implementation Notes
- 修改 `nginx/` 探活/CSP 收敛 + 新增 runbook（docs 部署清单内）；探活为静态站 nginx 层实现，无应用代码改动。
