# 4.5: 身份源管理页（UF-7）：连接参数表单 + 测试连接 + 启停

## Description
落地 /identity-sources：`idpList` store + `identity-sources.ts` api（list/create/update/delete/test/toggle）。表格（名称/类型/启用/操作）+ 新增/编辑 Dialog（6 字段连接参数：地址/端口/Bind DN/Bind 密码/Base DN/用户属性映射/超时）+ 测试连接 + 启停。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 身份源管理 UF-7：Layout/States（连接失败）/Interactions（6 字段表单/测试连接/启停）/Data Binding（Bind 密码掩码） (ref: 身份源管理)
- docs/features/platform-console/design/tech-design.md — C 档 identity_source 端点（ConnParams、test 通断）、ConnParams 模型 (ref: Interfaces / Data Models)

## Acceptance Criteria
- [ ] idpList store（统一契约）+ identity-sources.ts api（list/create/update/delete/test/toggle）+ 写前守卫/回读接入
- [ ] 6 字段表单：地址（ldap(s)://host:port）、端口（1–65535）、Bind DN、Bind 密码（仅写入/掩码不回显/留空沿用原值）、Base DN、用户属性映射（用户名必填）、超时（1–30s 默认 5）
- [ ] 校验：地址/Base DN/Bind DN/用户名属性非空，地址/端口/超时格式范围校验；凭据掩码不回显明文
- [ ] 测试连接：保存前可测试，成功/失败提示（测试响应类型化）
- [ ] 启停 toggle：状态更新（启用维持开关形态不套徽章）

## User Stories
Story 2（配置身份源、配置保存后该身份源可用于登录）承接。

## Hard Rules
Bind 密码仅写入、掩码展示、不回显已存明文（编辑态留空 = 不修改）；敏感凭据不得落日志或列表响应回显。

- 仅新增：`src/views/identity-sources/`、`src/stores/idpList.ts`、`src/api/identity-sources.ts`。
- 启停端点以 Phase 0（1.1）核验为准（eiam 实有 toggle/:id，承接 eval 残留 #1）；test 响应形状 C 档推定，核验后固化。
