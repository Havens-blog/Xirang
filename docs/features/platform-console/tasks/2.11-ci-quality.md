# 2.11: CI 质量闸门（typecheck/build/gzip 预算/漂移对比/vitest）

## Description
落地 CI：vue-tsc typecheck + vite build、gzip ≤300KB 预算检查（dist/**/*.gz）、sha256 漂移对比（从 e-cam-web checkout 源文件重算 vs shared-hashes.json）、vitest。性能预算三列对齐。

## Reference Files
- docs/features/platform-console/design/tech-design.md — 拷贝面漂移防线 CI job、性能预算表（首屏 gzip ≤300KB 三列分解） (ref: Architecture / 性能预算)
- docs/features/platform-console/prd/prd-spec.md — 性能达标（首屏静态 gzip ≤300KB、LCP ≤2.5s） (ref: Goals / Performance Requirements)

## Acceptance Criteria
- [ ] typecheck（vue-tsc）+ build job；vitest job
- [ ] gzip 预算 CI：汇总 dist/**/*.gz，超 300KB 即 fail（entry≤60 + element-plus≤140 + vue/router/pinia≤50 + 其余≤50）
- [ ] 漂移对比 job：e-cam-web checkout 3 个拷贝面源文件重算 sha256 vs shared-hashes.json，不一致→红
- [ ] 漂移红时要求：同步拷贝 + hash 更新 + 跑一条主题冒烟 E2E，漂移来源 commit 记入变更记录

## User Stories
No direct user story mapping.（工程化基础设施）

## Hard Rules
性能预算超限必须 fail，不得放宽后放行；漂移对比只能以 e-cam-web 对应 commit 源文件为准。

## Implementation Notes
- 仅新增：CI 配置（GitHub Actions 或等价，路径随仓而定）+ 构建期 .gz 预生成脚本衔接。
- gzip 预算测量手段 = 构建脚本汇总 dist/**/*.gz；LCP 采样由 E2E（2.12 起）承接。
