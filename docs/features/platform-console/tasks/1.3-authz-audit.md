# 1.3: 服务端授权核查（CRUD 端点鉴权确认）

## Description
逐端点确认 eiam 对所有 CRUD 端点做服务端强制鉴权与授权（前端菜单裁剪仅为体验层、非安全边界）。产出授权核查矩阵，缺失端点进入缺口处置。

- docs/features/platform-console/prd/prd-spec.md — 服务端强制授权、Phase 0 核查矩阵逐端点确认 (ref: Security Requirements)

## Acceptance Criteria
- [ ] 覆盖 1.1 反推出的全部管理端点（user/role/tenant/organization/identity_source/policy/authorization CRUD + reset_password + passkey 注册/撤销）
- [ ] 逐端点登记：是否服务端鉴权、鉴权方式（session/JWT）、授权粒度（平台级/租户级/越租户阻断）
- [ ] 前端裁剪与 403 后端兜底的对应关系逐端点标注（越权请求返回 403 的路径确凿）
- [ ] 缺失授权保护的端点 → 登记缺口处置（eiam 补齐 / 该流裁剪），不得静默放行

## Hard Rules
仅产出核查矩阵；发现授权缺口只登记 + 报告，不在本阶段修复。结论须证据支撑（eiam 中间件/路由鉴权代码 文件:行号）。

## Implementation Notes
- 与 1.1 的端点清单对齐，逐条闭环；越界访问（Story 3 AC 的 403 兜底）依赖本核查的可信度。
