# 3.3: 工作台（UF-3）：欢迎 + 我的信息 + 应用快捷导航

## Description
落地 /workbench：欢迎横幅 + 我的信息（用户名/昵称/所属租户/角色四字段只读）+ 应用快捷导航卡片（1280–1599px 2 列、≥1600px 3 列）。进入时按 eiam 所属租户查询二选一 Default/受限视图（0 个 → 受限）。

## Reference Files
- docs/features/platform-console/ui/ui-design.md — 工作台 UF-3：Layout/States（Default/受限视图/eiam 不可用）/Interactions/Data Binding、受限视图口径 (ref: 工作台)
- docs/features/platform-console/design/tech-design.md — 工作台/我的信息数据源（profile 六字段）、应用卡片本地枚举 (ref: Architecture / Data Models)

## Acceptance Criteria
- [ ] 欢迎横幅 + 我的信息四字段（profile：用户名/昵称/所属租户/角色）只读展示
- [ ] 应用快捷导航卡片：1280–1599px 2 列、≥1600px 3 列（定死两断点），点击新标签跳对应应用/云管页
- [ ] 受限视图（零租户 E3）：仅欢迎+我的信息，卡片禁用，管理菜单不渲染；URL 直入管理页提示「无所属租户」不白屏
- [ ] eiam 不可用（E12）：静态内容仍渲染 + 顶部降级提示，卡片跳转禁用

## User Stories
Story 1（欢迎语/我的信息/应用快捷导航）、Story 3（零租户受限视图）的工作台承接。

## Hard Rules
应用卡片清单本地穷举（v1 仅云管），不做运行时注册；受限视图不得白屏。

## Implementation Notes
- 仅修改：`src/views/workbench/`（或 views/Workbench.vue）。与 3.2 共用受限视图块（含 tenant.none 文案）。
- profile 数据源 = 2.7 user store，无需额外端点。
