WatchAlert 子项目并入 — 原型导航

三个 UI 功能对既有前端页面的改造：eiam 统一登录（组件 1）、鉴权不可用宽限横幅（组件 2）、只读免登录视图（组件 3）与 403 占位（组件 4）。每页底部有「状态切换」控制条，可切换各状态。

登录页

组件 1：eiam 统一登录入口。移除本地账密，改为「使用平台账号登录」跳转。含 未登录 / 跳转中 / 登录失败 / 配置缺失 四态。

告警看板

组件 2 + 3 + 4：正常 / 宽限（横幅+写禁用）/ 只读（加载·有数据·空·错误）/ 403 四态。

告警规则

组件 2 + 3 + 4：共享横幅 + 只读规则列表（敏感字段脱敏）。

故障中心

组件 2 + 3 + 4：共享横幅 + 只读事件时间线。
